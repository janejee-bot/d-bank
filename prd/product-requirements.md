# 목표·수준·관심 분야에 맞는 온라인 강좌를 비교·추천해 주는 웹 플랫폼 기획문서

- 작성일: 2026. 8. 10. 13시 35분 32초 (KST)
- 작성 위치: ImpactVibe Studio / 기획
- 연결 흐름: Research 자료 → AI 대화 → 기획문서 → 제작

## 1. 개요
- 한 줄 정의: 목표·수준·관심 분야에 맞는 온라인 강좌를 비교·추천해 주는 웹 플랫폼
- 제품 목표: 사용자가 3분 안에 목표에 맞는 강좌 후보 3개를 받고, 그중 1개를 상세 확인·저장할 수 있게 한다
- 배경: 온라인 강좌가 많아졌지만 플랫폼·가격·난이도·후기가 흩어져 있어, 초보 학습자가 무엇을 들을지 고르기 어렵다

## 2. 문제 및 해결 방안
### 사용자 문제
검색만으로는 내 목표·현재 수준에 맞는 강좌를 빠르게 찾기 어렵고, 비슷한 강의 간 차이를 비교하기 힘들다

### 해결 방안
목표·관심 분야·난이도·예산·학습 시간을 입력하면 조건에 맞는 강좌를 점수화해 추천하고, 카드형 비교·상세·관심 저장을 제공한다

### 차별점
단순 인기순이 아니라 사용자 입력 조건 기반 매칭 점수와 나란히 보기 비교로 ‘왜 이 강좌인지’를 바로 보여 준다

## 3. 타겟 및 시나리오
### 타겟 사용자
취업·이직·직무 역량 향상을 위해 온라인 강좌를 찾는 취준생·주니어 직장인·평생학습자

### 사용자 시나리오
취준생이 ‘프론트엔드 입문, 주 5시간’를 입력 → 추천 3개를 받고 → 두 강좌를 비교한 뒤 관심 목록에 저장한다

## 4. 성공·위험 요소
### 핵심 지표
추천 완료율 70% 이상, 추천 후 상세 조회율 50% 이상, 관심 저장 전환율 20% 이상, 추천 결과 만족도(5점 척도) 평균 4.0 이상

### 리스크
초기 강좌 데이터·후기 부족으로 추천 신뢰도가 낮을 수 있고, 출처·가격 정보가 오래되면 이탈이 늘어날 수 있다

## 5. 속성 설정
- 카테고리: 에듀테크 / 콘텐츠 추천
- 사용자 역할: 학습자, 관리자
- 기기: 웹(데스크톱), 모바일 웹

## 7. 유저플로우
### 진입·경로 선택
- 웹 서비스 진입 (start) — 데스크톱 또는 모바일 웹으로 홈에 들어와 학습자/관리 경로를 본다
- 이용 경로 선택 (branch) — 맞춤 추천, 강좌 탐색, 관심 목록, 관리자 중 하나를 고른다

### 맞춤 추천
- 학습 조건 입력 (key) — 목표·관심 분야·난이도·예산·주간 학습 시간을 폼에 입력한다
- 필수값 검증 (branch) — 목표·관심 분야·난이도 누락 여부를 확인하고 통과 시에만 추천을 진행한다
- 누락 안내 확인 (key) — 비어 있는 필수 필드 안내를 보고 값을 보완한다
- 추천 결과 확인 (key) — 매칭 점수 상위 강좌 카드(최대 3개)와 점수·추천 이유를 본다
- 추천 후 행동 선택 (branch) — 상세 보기, 비교 담기, 관심 저장, 조건 수정 중 다음 행동을 고른다
- 조건 수정 후 재추천 (key) — 이전 값이 채워진 폼에서 조건을 바꿔 다시 추천을 받는다

### 상세·비교·관심
- 강좌 상세 확인 (key) — 가격·난이도·학습 시간·목차·출처와 매칭 점수·이유를 한 화면에서 본다
- 상세 후 행동 선택 (branch) — 관심 저장, 비교 담기, 목록 복귀 중 하나를 선택한다
- 비교 대상 담기 (key) — 추천·목록·상세에서 강좌를 비교 바구니에 최대 3개까지 담는다
- 비교 가능 여부 (branch) — 비교 대상이 2개 이상이면 비교 화면으로, 아니면 추가 선택을 유도한다
- 나란히 비교표 확인 (key) — 가격·난이도·학습 시간·점수·추천 이유를 표로 비교하고 대상을 추가·제거한다
- 관심 저장/해제 (key) — 추천 카드·상세에서 관심을 저장하거나 해제하고 즉시 피드백을 본다
- 관심 목록 조회 (branch) — 저장 목록을 열고, 비어 있으면 추천/탐색으로, 있으면 항목 상세로 간다
- 관심 강좌 확정 (leaf) — 저장한 후보를 다시 확인하며 수강 후보를 좁힌다

### 강좌 탐색
- 강좌 목록 브라우징 (key) — 전체 또는 분야별 강좌 목록에서 이름·분야·난이도·가격을 훑는다
- 필터·정렬 적용 (key) — 분야·난이도·가격 필터와 정렬 기준으로 목록을 좁히고 순서를 바꾼다
- 탐색 후보 선택 (branch) — 목록 항목에서 상세 보기, 비교 담기, 관심 저장 중 하나를 고른다

### 관리자 데이터 관리
- 관리 목록·검색 (key) — 등록 강좌를 목록·검색으로 보고 상태(노출/비노출)를 확인한다
- 등록 또는 수정 선택 (branch) — 새 강좌 등록과 기존 강좌 편집 중 작업을 고른다
- 강좌 등록 저장 (key) — 이름·분야·난이도·가격 등 필수값을 채워 새 강좌를 저장한다
- 강좌 수정·노출 변경 (key) — 기존 정보를 수정하거나 노출을 끄고 켜 학습자 반영 대상을 바꾼다
- 학습자 반영 확인 (leaf) — 저장 결과가 학습자 추천·목록·상세에 반영된 것을 확인한다
